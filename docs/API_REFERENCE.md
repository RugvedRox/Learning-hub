# 🔧 API Reference\n\n## Base URL\n\n```\nhttps://your-backend.railway.app/api\n```\n\n## Authentication\n\nAll protected routes require JWT token in header:\n\n```\nAuthorization: Bearer <token>\n```\n\n## Auth Endpoints\n\n### Register\n\n```http\nPOST /auth/register\n```\n\n**Body:**\n```json\n{\n  \"email\": \"user@example.com\",\n  \"password\": \"password123\",\n  \"fullName\": \"John Doe\",\n  \"gradeLevel\": \"grade-4-6\"\n}\n```\n\n**Response:**\n```json\n{\n  \"token\": \"jwt_token_here\",\n  \"user\": {\n    \"_id\": \"user_id\",\n    \"email\": \"user@example.com\",\n    \"fullName\": \"John Doe\",\n    \"gradeLevel\": \"grade-4-6\"\n  },\n  \"message\": \"Account created successfully!\"\n}\n```\n\n### Login\n\n```http\nPOST /auth/login\n```\n\n**Body:**\n```json\n{\n  \"email\": \"user@example.com\",\n  \"password\": \"password123\"\n}\n```\n\n### Get Profile\n\n```http\nGET /auth/profile\n```\n\n**Headers:**\n```\nAuthorization: Bearer <token>\n```\n\n### Update Profile\n\n```http\nPUT /auth/profile\n```\n\n**Body:**\n```json\n{\n  \"fullName\": \"Jane Doe\",\n  \"avatar\": \"https://...\",\n  \"theme\": \"dark\",\n  \"gradeLevel\": \"grade-7-9\"\n}\n```\n\n## AI Tutor Endpoints\n\n### Ask Question\n\n```http\nPOST /ai-robot/ask\n```\n\n**Body:**\n```json\n{\n  \"question\": \"What is photosynthesis?\"\n}\n```\n\n**Response:**\n```json\n{\n  \"conversationId\": \"id\",\n  \"question\": \"What is photosynthesis?\",\n  \"answer\": \"Photosynthesis is...\",\n  \"category\": \"science\",\n  \"questionsAskedToday\": 45,\n  \"maxQuestionsPerDay\": 100,\n  \"remainingQuestions\": 55\n}\n```\n\n### Get History\n\n```http\nGET /ai-robot/history/:userId\n```\n\n## Quiz Endpoints\n\n### Generate Quiz\n\n```http\nPOST /quiz/generate\n```\n\n**Body:**\n```json\n{\n  \"topic\": \"Photosynthesis\",\n  \"numberOfQuestions\": 10\n}\n```\n\n### Search Quizzes\n\n```http\nGET /quiz/search?q=photosynthesis&difficulty=medium\n```\n\n### Get Quiz\n\n```http\nGET /quiz/:quizId\n```\n\n### Submit Answers\n\n```http\nPOST /quiz/:quizId/submit\n```\n\n**Body:**\n```json\n{\n  \"answers\": [\n    {\"questionId\": 1, \"answer\": \"Option A\"},\n    {\"questionId\": 2, \"answer\": \"True\"}\n  ],\n  \"timeTaken\": 1200\n}\n```\n\n## Status Codes\n\n| Code | Meaning |\n|------|----------|\n| 200 | OK |\n| 201 | Created |\n| 400 | Bad Request |\n| 401 | Unauthorized |\n| 403 | Forbidden |\n| 404 | Not Found |\n| 429 | Too Many Requests |\n| 500 | Server Error |\n\n## Error Response\n\n```json\n{\n  \"error\": \"Error message here\"\n}\n```\n
